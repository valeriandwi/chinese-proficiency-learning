# Third-party data and licensing

Every dataset this app depends on, what it obliges us to do, and where the
obligation is discharged in the code. If you add a source, add a row.

## 1. Hanzi stroke-order data — Arphic Public License

**What it is.** The SVG path geometry and stroke order for each character, so a
learner can trace a character and be told which stroke was wrong.

**Where it comes from.** The `hanzi-writer-data` package, derived from the
Make Me a Hanzi project, which extracted it from the Arphic PL KaitiM GB and
Arphic PL UKai fonts. Copyright © Arphic Technology Co., Ltd.

**What the licence requires.**
- Commercial use is permitted.
- The licence text must travel with the data: it is copied to
  `web/public/hanzi/LICENSE.txt` by `web/scripts/copy-hanzi-data.mjs` and is
  served alongside the character files.
- Modifications must be marked. We do not modify the geometry: the files are
  copied byte for byte, and the indexes we build on top of them (the
  handwriting-signature and component indexes) carry the notice in the index
  file itself.
- Attribution: the app footer credits Make Me a Hanzi and the Arphic Public
  License, and `web/scripts/copy-hanzi-data.mjs` refuses to run if it cannot find
  the licence text.

**Risk if ignored.** Redistributing the data without the licence text is a
licence breach, not a technicality. That is why the copy step fails loudly rather
than writing a placeholder.

## 2. Vocabulary placement — published HSK word lists

**What it is.** Which word belongs to which HSK level. This is the spine of the
curriculum: `lexeme_levels` maps a word to a level in a curriculum version.

**Where it comes from.** The word lists published by Chinese Testing
International / the Center for Language Education and Cooperation for HSK 2.0
(six levels) and HSK 3.0 (three stages, nine levels). Factual level placement of a
word is not itself creative expression, but the official lists are the authority
and HSK is a trademark of the administering body. Do not present this app as
endorsed by them.

The lists are collected from the **Complete HSK Vocabulary** project
(https://github.com/drkameleon/complete-hsk-vocabulary), file
`wordlists/exclusive/old/{2,3,4,5}.json` — "exclusive" being the words a level
newly introduces, which is what that level's syllabus is. That collection is
**MIT licensed**; its notice, the exact fetch command and the date it was fetched
are in `content/hsk2.0/VOCABULARY-LICENCE.txt`, and the raw JSON is fetched into
the gitignored `.local/` rather than committed. What is committed is the derived
spine in `content/hsk2.0/level-{2..5}.yaml`, generated by `cmd/contentgen`.

**What follows from it.**
- Word lists are marked in `content/**/*.yaml` and are what the importer expects.
- The app must not claim official status; `docs/roadmap.md` and the UI copy say
  "aligned with", never "official".
- Level 1's 46 lexemes were authored by hand; levels 2–5 are the complete derived
  lists. Re-generating is `make content-gen validate import`, and the file's own
  notice says which is which.

## 3. Definitions and senses — authored, with gaps filled from CC-CEDICT

**What it is.** The English gloss on every vocabulary card, e.g. 你 → "you".

**Where it comes from.** Authored for this application. Where a gloss is taken
from CC-CEDICT, it is **CC BY-SA 4.0**, which is share-alike: an adapted
definition must carry the same licence, and attribution is required.

**Where levels 2–5's glosses come from, and an unresolved risk to respect.**
Level 1's glosses are authored. Levels 2–5 take the first usable sense from the
MIT-licensed collection named in §2, and that collection's definitions are visibly
of the same family as CC-CEDICT (entries read like `bar (loanword) (serving
drinks, or providing Internet access etc)`). Two consequences:

- We rely on the upstream project's **MIT declaration** for those glosses. If a
  gloss is in fact an adapted CC-CEDICT definition, CC BY-SA 4.0's share-alike
  applies to it regardless of how the collection labels itself, and the collection
  does not mark per-entry provenance — so this cannot be resolved by reading it.
- **Therefore, before this content is used commercially, the glosses must be
  either replaced with authored ones, or attributed and licensed as CC BY-SA with
  a shipped attribution page.** Until then the position is: development content,
  provenance flagged, no commercial claim made about the definitions. This is
  recorded here rather than silently accepted because a licence question is not
  something a passing test can close.

The generator's own filters (`cmd/contentgen`, `glossNoise`) drop dictionary
conventions like "surname X" and "variant of X" so a drill teaches a real meaning,
which is a quality fix, not a licensing one.

**Consequence to respect.** Do not mix CC-CEDICT-derived glosses into authored
content without marking them. Keep a `source` field per sense if CC-CEDICT
definitions are imported wholesale, and ship the attribution page.

## 4. Example sentences and passages

**Where it comes from.** Authored for this application (`content/hsk2.0/level-1.yaml`).
Level 1 is original work; the reference answers shown to a learner after a writing
exercise are ours.

**Consequence.** If a corpus (Tatoeba, a textbook, a publisher's material) is ever
imported, record its licence here first — the passages carry the sentence text
verbatim into the app and into the database.

## 5. Reference audio — generated locally, licence recorded per provider

**What it is.** The spoken reference clip for every listening drill, speak_repeat
prompt and listening passage. 17 assets are referenced by the authored Level 1
content today.

**Where it comes from.** Generated at import time by `internal/media`: the
`TTSProvider` interface is implemented by a macOS `say` provider (voice
`Tingting`, Chinese mainland), and ffmpeg transcodes the result to 64 kbps mono
MP3. Keys are a hash of (provider, voice, text, format), so an asset is immutable
and an edit to a sentence produces a new file rather than a stale pronunciation.

**Licence status — read before shipping to end users.**
- The **MacSayProvider** exists so the pipeline is exercisable offline and in
  tests with no credentials. Audio synthesised by an operating-system voice is
  governed by *Apple's* terms (macOS software licence agreement), not ours, and
  those terms do not clearly permit redistributing the output as a product
  asset. Treat it as a **development provider**: it is the default in
  `development`, and serving its output to real learners in production is a
  decision that has not been taken.
- A production deployment must select a provider whose terms explicitly allow
  storing and serving the generated audio, configured via `TTS_PROVIDER`, and
  that clause must be recorded here — with the vendor's name, the date it was
  checked, and any attribution the terms require — **before** the audio is
  served. `TTS_PROVIDER=none` disables synthesis, and any import of content that
  needs audio then fails loudly rather than shipping a silent lesson.

**What we already discharge.**
- Nothing generated is distributed outside this repository's dev environment.
- The generated assets live in `MEDIA_DIR` (gitignored), not in the repo, so a
  licence decision is not baked into a commit.
- Every listening item's answer key carries its transcript, so a transcript can
  always be shown even if an audio asset has to be withdrawn.

## 6. Software

Go: chi (MIT), pgx (MIT), goose (MIT), x/crypto (BSD-3), yaml.v3 (MIT/Apache-2.0).
Web: React (MIT), Vite (MIT), Tailwind CSS (MIT), React Router (MIT), TanStack

hanzi-writer-data (Arphic PL for the data, MIT for the packaging), Vitest (MIT),

Added with the Duolingo-inspired interface (see `docs/architecture.md`, "The
interface is a system, not a stylesheet"):
- **lucide-react** — ISC licence. The icon set. ISC permits commercial use and
  needs no attribution in the interface.
- **Nunito variable** (`@fontsource-variable/nunito`) — SIL Open Font License
  1.1. The interface typeface. OFL permits commercial use, including bundling and
  serving from our own origin; the licence text travels with the package at
  `node_modules/@fontsource-variable/nunito/LICENSE`.

Both are **bundled by Vite and self-hosted**. Nothing is fetched from a
third-party font or icon CDN at runtime: the app renders the same offline, and no
request leaks a learner's session to another origin. `src/lib/design-tokens.test.ts`
fails the build if a CDN reference ever appears in the stylesheet.
